# Condition rules

The registry currently detects textual evidence for charges, flasks, enemy low-life, and recently-killed settings. These are deliberately classified as `Unverified` until a source can be traced to gems, items, passives, ascendancy data, or a supported PoB field.

Planned rules include Rage, Berserk, guard skills, Sigil stages, ailments, exposure, curses, ramp mechanics, projectile overlap, ground effects, and manual modifiers. Unsupported mechanics must remain unknown rather than invalid.
