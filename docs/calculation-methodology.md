# Calculation methodology

Phase 1 does not calculate DPS, effective hit pool, uptime, or alternate defensive values. It displays no fabricated numbers.

Future scenarios will call a pinned Headless PoB version for each explicit configuration, then use a timeline of states. Sustained DPS will be `sum(state DPS × state duration) / encounter duration`; no universal uptime multiplier will be applied. Every estimate will include assumptions, confidence, and the exact scenario configuration.
