# Calculation methodology

Phase 1 does not calculate DPS, effective hit pool, uptime, or alternate defensive values. It displays no fabricated numbers.

Combat scenarios call the pinned Headless PoB version for each explicit configuration, then use a timeline of states. Alternate profiles reset supported conditional inputs before enabling only source-backed conditions detected in the imported build. Unsupported or unverified configured inputs are not silently carried into peak, burst, initial, or mapping results. Reliable minimum-charge sources, such as an ascendancy minimum-charge modifier, remain active in the initial state.

Sustained DPS is `sum(state DPS × state duration) / encounter duration`; no universal uptime multiplier is applied. The current timeline uses an engine-calculated initial state, a five-second burst assumption, and the configured imported state for the remaining encounter. The burst duration and remaining-state behavior are explicit limitations, not claims of guaranteed uptime. Every result includes its active conditions, assumptions, confidence, and the pinned engine response.
